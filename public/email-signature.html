Gmail: Settings (gear) → See all settings → Signature → Create new → paste → Save changes.
Outlook (web): Settings → Mail → Compose and reply → paste into the signature box → Save.
Apple Mail: Mail → Settings → Signatures → paste (uncheck “Always match my default message font”).
